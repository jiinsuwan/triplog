# GPT 이미지 편집 프롬프트 — 인스타 감성 다꾸 (참조 자산)

> 출처: 사용자가 공유한 레퍼런스 게시물의 실제 프롬프트.
> 용도: **이미지 편집 AI(GPT-4o image / nano-banana 등)에게 원본 사진을 주고 "감성 편집"을 시킬 때** 그대로 붙여넣는다.
> TripLog의 canvas 자동 합성(render-core.mjs)과는 **다른 트랙** — 이쪽은 AI가 픽셀을 직접 편집한다. 두 방식은 상호 보완.

---

## 공통 프롬프트 (원본 사진 첨부 후 사용)

```
업로드한 원본 사진을 기반으로 편집해주세요.

핵심 원칙:
- 원본 사진의 구도, 피사체, 음식 형태, 배치, 실제 요소는 최대한 그대로 유지
- 새로운 사물, 인물, 배경을 추가하지 말 것
- 사진 자체를 재창작하지 말고 "감성 편집"만 진행

편집 스타일:
- 인스타 스토리 + 감성 다이어리 + 매거진 낙서 무드
- 자연스럽고 여백 있는 세련된 분위기
- 과한 디자인 느낌 없이, 사진 위에 가볍게 손으로 꾸민 느낌

추가 요소:
- 음식이나 주요 오브젝트 주변에 흰색 점선, 얇은 손그림 라인, 화살표 등으로 자연스럽게 강조
- 작은 별, 반짝임, 물결, 점 등의 감성 낙서를 은은하게 추가
- 전체 화면 밸런스를 해치지 않도록 배치

텍스트 요소:
- 오브젝트 주변에 짧은 한글 손글씨 메모 추가
- 음식의 느낌, 분위기, 맛 표현, 혼잣말 같은 자연스러운 문장
- 전체 장면을 표현하는 짧은 감성 문장 1개 포함

최종 결과:
- 원본 사진은 유지되지만 훨씬 감각적이고 센스 있어 보이는 콘텐츠 이미지
- 실제 인스타 감성 편집본처럼 자연스럽게 만들어주세요
```
