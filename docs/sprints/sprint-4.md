## 이번 스프린트 작업
> **진행 순서: 1) 디자인 반영 → 2) 필수 완비 → 3) 추가(되는대로) → 4) 산출물.** 각 항목 = GitHub Issue. 발행 분담 = log 담당자(core+log) / trip 담당자(trip). trip 항목은 팀원 협의안 기준이며, **이슈 번호는 발행 시 팀원과 조율해 확정**한다.
