인증 — 디자인 정의 (Sprint 4 · 이 목업이 구현 정본)
  • 여권 레이아웃 = 좌 남색 표지(도장 잉크색 = 여권 표지) + 우 폼. 로그인·회원가입·비밀번호 모두 같은 틀, 폼·카피만 교체
  • 표지 = 로고 + 점선 테두리 + 비행기 + 카피 + 도장 마크(여권 느낌). 버튼 = 테라코타(주 액션)
  • 폼 컴포넌트(label·input·block 버튼·form-link)는 design-system.css에 추가 — 다른 화면 재사용
  • 로그인 화면에 비밀번호 찾기·회원가입 링크. 모바일 반응형 = 추후(데스크톱 우선)
