## v12에서 추가된 것 (전부 `outline_module.py`)

- 운반대 강등 + 확대 재검출(SAHI식) + **내부 점-격자 구제**(어휘 무관, 표면조각 기각)
- saliency 커버리지-갭 구제 (거대 주인공 미검출 구제 — 0956 회 플래터)
- **이중 포커스 자동 해소**: 마스크 포함형(파편/내용물⊂전체→전체 유지) + bbox 포함형(접시 고리→채움밀도 높은 쪽 유지)
- group 버블 2종: hull(떨어진 묶음) / smooth(한 덩어리 대형 — 합집합 완전성이 품질 좌우)
- 텍스트 앵커(외곽선 비겹침 배치 후보) — LLM 최초 배치 규칙은 OUTLINE_API §2-1
- 무드 톤다운 실측: ref = 밝은 영역 보존·어두운 영역 강압 톤커브, 중앙값 ≈ 감마 1.55 (슬라이더 35%)
- FastAPI 사이드카 + 보정 결과 item 등록("그룹에 추가")

## 결과 (ref 5장)

5/5 레퍼런스 수준 도달 — 사진당 사람 클릭 0~3회. 전처리 2~16s/장, 탭 1.1s, group 0.02s (CPU).
미해결: 어두운 불판 림 정밀 추종(+/− 클릭 정제 후속 후보), grid/sal 항목 라벨 없음, 회귀는 5장 기준.
