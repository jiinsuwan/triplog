TripLog — AI 음식 카드 PoC 방법론 시도 회고

사진 → 인스타 감성 카드 자동 생성 PoC · 음식 영역 검출 + 카드 디자인 톤 실험 기록 · 작성 2026-05-30

이 문서의 목적 — "음식 사진 위에 손글씨/낙서를 얹은 인스타 감성 카드"를 자동 생성하기 위해, ① 음식 영역을 어떻게 검출할 것인가(컴퓨터비전)와 ② 카드 디자인 톤을 여러 방법으로 시도했다. 무엇을 시도했고, 어떤 결과가 나왔으며, 지금 무엇을 수정 중이고, 무엇이 미해결인지 정리해 다음 아이디어를 고민하기 위한 자료로 만든다.

0. 한눈에 보기 — 핵심 결론

  • 카드 렌더 엔진은 완성도 높음. Canvas2D 공용 코어(render-core.mjs)로 JSON→PNG 양산 + 브라우저 편집기까지 동일 코어 공유. 손글씨·반짝이·오버레이·점선·누끼 마스크 다 지원.
  • 음식 영역 검출이 가장 어려운 미해결 지점. rembg→FastSAM→SAM2→색기반→hull 순으로 진화. 현재 SAM2 large + box-prompt가 "접시+음식 통째"를 가장 정밀하게 잡음.
  • 핵심 미결정: 외곽선이 접시째를 감쌀지 음식 내용물만 감쌀지 방향이 계속 흔들림. 음식이 빽빽한 사진은 코멘트 둘 여백도 부족.
  • 결정된 방향: 자동(SAM2)은 80%만 잡고 나머지는 편집기에서 사용자가 점 드래그/뭉툭 슬라이더로 보정한다 = "AI 자동 + 사용자 편집". (편집기 보정 UI는 미구현)

1. 카드 디자인 톤 — 진화 과정

사용자 피드백을 받아가며 톤이 6단계로 바뀌었다. (일부 중간 단계는 카드 JSON을 덮어써서 PNG가 유실 → 설명으로 대체)

단계시도한 톤사용자 피드백 / 결과
1캡션형(잡지 표지) — 큰 손글씨 제목 + 물결 밑줄. 4사진 × 4스타일(minimal/rich/info/polaroid) = 16종"따로 노는 느낌" — 인스타 다꾸 톤과 거리. 방향 전환
2말풍선형 — 사진 위 말풍선 박스 + 꼬리로 음식 코멘트"말풍선이 핵심이 아냐" — 예시는 홍보 게시물이라 말풍선이 과했던 것 PNG 유실
3흰 손글씨 낙서 — 박스 제거, 사진 위 흰 펜 글씨 + 점선"배경 어둡게 해야 글씨가 산다" PNG 유실
4폰트 교체 — 나눔펜 → Gamja Flower(둥근 손글씨) + 어두운 오버레이톤 크게 개선
5리서치 반영 — 반짝이 ✦, 따뜻한 톤(soft-light), 강조색, 워터마크, 누끼 흰테두리예시 톤에 근접
6프롬프트 발견 → 톤다운 — 사용자가 공유한 GPT 편집 프롬프트("원본 유지·은은·과하지 않게") 반영현재 진행 — 음식 외곽 강조 방식에서 막힘

2. 음식 영역 검출 방법론 — 핵심 실험

"음식을 어떻게 잡을 것인가"가 가장 많이 갈아엎은 부분이다. 시간순으로:

#방법의도결과판정
2-1rembg (u2net) 배경제거주제 누끼로 객체 강조"두드러진 하나"만 따는 saliency라 접시 4개 분리 구조적 불가불가
2-2FastSAM everything클래스 무관 전체 인스턴스 자동 분리사람·빈 배경을 잡고 정작 음식 접시는 놓침실패
2-3FastSAM box-prompt (vision bbox)음식 위치를 프롬프트로 한정접시는 잡으나 윤곽 거침(폴리곤 11~38점)거침
2-4SAM2 box (base)FastSAM보다 정밀한 SAM2윤곽 촘촘(28~90점). 단 우하단 삐침 노이즈개선
2-5SAM2 point-prompt (음식 중앙 1점)접시 말고 음식만 분리메인 파스타·피자는 음식 정확히 땄으나, 흩어진 음식(감자)은 한 조각만(frac 0.001)부분
2-6multi-point (음식 그리드 9점)흩어진 음식 전체 커버API 형식 문제로 9점을 9객체로 해석 → 더 작게실패
2-7색 기반 (접시 표면색 제외)접시 안에서 음식만 색으로 분리음식 영역 조각남(frac 0.002~0.026), 무늬 접시에서 흔들림실패
2-8SAM2 large + morphology마스크 품질↑ + 삐침/구멍 제거접시+음식 통째를 삐침 없이 정밀하게 (현재 베이스)정밀
2-9convex hull + 5% 확대"뭉툭하게" 둥근 외곽볼록 껍질이 음식 凹부분을 직선으로 가로지르고 확대로 접시 밖 테이블까지 둘러 이상해짐과함
2-10원본 contour + smooth (현재)확대 빼고 윤곽 따라가며 둥글게마스크 저장 → SAM 없이 round_outline.py로 뭉툭 정도 즉시 조절조정중

리서치로 확정한 추천 파이프라인

FastSAM/SAM2 box-prompt(음식 위치)  →  인스턴스 마스크
   →  pymatting / OpenCV feather (경계 부드럽게, hard edge 제거)
   →  cv2.findContours + approxPolyDP (외곽 폴리곤)
   →  canvas 점선 손그림 강조선

3. 외부 리서치 발견 (검색 기반)

3-1. 컴퓨터비전 (음식 세그멘테이션)

  • FastSAM-s(23.9MB, AGPL): 빠르나 거침. SAM2(b/l): 느리나 정밀 — 현재 채택(large).
  • 경계 부드럽게: pymatting alpha matting(trimap), 또는 OpenCV erode+GaussianBlur feather.
  • 외곽선: cv2.findContours + approxPolyDP로 폴리곤화, Canny/HED는 질감 있는 선.
  • 상업 폐쇄소스 시 AGPL 주의 → MobileSAM(Apache) 대안.

3-2. 인스타 감성 카드 디자인

  • 폰트 1~2종 제한 / 메인:코멘트 ≈ 2.2:1 / 강조 1색만 (크림 #FFF8E7).
  • 반짝이 6~10개 상한(과하면 촌스러움), 그림자 약하게(blur 8/op 0.3).
  • 누끼 = 흰 외곽선 2px + soft 그림자 + 배경 블러(스티커화).
  • 색온도 +warm, 그레인 20~30, 폴라로이드 하단 띠에 날짜·장소.

4. 현재 미해결 과제 / 고민거리

이슈현황 / 고민
접시 vs 음식외곽선이 "접시째"인지 "음식 내용물"인지 방향이 계속 흔들림. 현재는 "접시+음식 통째(box)". 음식만 분리는 무늬 접시/흩어진 음식에서 까다로움.
뭉툭함윤곽이 음식 굴곡을 그대로 따르면 들쭉날쭉. 너무 뭉툭(hull+확대)하면 접시 밖으로 뜸. smooth·expand 균형점 탐색 중.
경계 자연스러움foodmask hard edge → GaussianBlur(45)로 완화. pymatting 정밀 매팅은 미적용(맥 CPU 속도).
코멘트 배치음식이 빽빽한 사진(IMG_9717)은 글씨 둘 어두운 여백이 좁아 음식을 가림. 여백 많은 사진은 수월.
자동 정밀도 한계SAM2도 100%는 불가 → 편집기 수동 보정으로 메우는 게 결론. (UI 미구현)

6. 다음 아이디어 후보

  1. 편집기 외곽선 보정 UI — SAM2 자동 외곽을 점 핸들로 표시, 드래그/추가/삭제 + 뭉툭 슬라이더. (가장 실용적, 결론적 방향)
  2. 음식 vs 접시 결정 — 둘 중 하나로 확정하거나, 편집기에서 토글.
  3. 경계 매팅 정밀화 — pymatting trimap을 다운스케일로 적용해 속도/품질 절충.
  4. 여백 많은 사진 우선 — 코멘트 배치가 자연스러운 사진(캠핑·분식)으로 톤 확정 후 빽빽한 사진 대응.
  5. HQ-SAM / SAM2.1 large+ 등 더 높은 품질 모델, 또는 음식 전용 세그 모델 검토.
  6. GPT 이미지 편집 트랙 병행 — canvas 자동 합성과 별개로, 사용자가 직접 GPT로 감성편집(프롬프트 자산 활용).
요약 한 줄 — 렌더 엔진·편집기·세그 파이프라인 골격은 섰고, 남은 핵심은 "음식 외곽을 어느 수준(접시째/음식만, 얼마나 뭉툭)으로 잡고, 부족분을 편집기에서 어떻게 보정하게 할 것인가"의 디자인 결정이다.
