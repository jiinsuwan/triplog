## 1. 제품 정의

**한 줄 정의**: 지도 기반 여행 계획 · 사진 기반 여행 기록 · AI 기반 공유 콘텐츠 생성을 연결하는 여행 로그 서비스.

**3단계 사용자 여정**:

| 단계 | 동사 | 핵심 행위 | AI의 역할 |
|---|---|---|---|
| 여행 전 | **Plan** | 여행 생성, 관광지 탐색, 일정 구성 | (P1+) 챗봇으로 관광지 요약·추천 이유 설명 |
| 여행 중 | **Capture** | 사진 업로드, 메모, 위치/시간 메타 | (없음 — 사용자가 직접 정리. 자동 태깅은 P2) |
| 여행 후 | **Share** | AI 카드 생성, PNG 다운로드 | **사진 위 overlay 카드 생성** — 짧은 문구 LLM + 코드 배치 (P0 핵심, [0004](decisions/0004-card-poc-result.md)) |

**차별점**:

1. 일정 앱이 아니라 **공유 콘텐츠 생성기** — 결과물이 앱 밖(SNS)으로 나간다
2. 사진 위 손그림 효과가 **객체 인식 기반으로 위치 결정** — 정적 스티커 짜깁기가 아님
3. **이미지 생성 LLM을 거의 사용하지 않는** 비용 통제 구조
4. **AI agent 기반 2인 협업 개발 방법론** 자체가 포트폴리오 핵심

## 5. 화면 구성 (요약)

### 5-0. 인증 (core 트랙)
- 로그인 / 회원가입
- 소셜 로그인 버튼 (카카오·구글·네이버) — P1

### 5-1. 메인 / 마이페이지 (core + 양 트랙)
- 내 여행 목록 (카드 그리드)
- "+ 새 여행"
- 프로필 수정 (마이페이지)

### 5-2. 여행 기획 (trip 트랙)
- 여행 생성 모달
- 관광지 탐색 (좌측 리스트 + 우측 지도)
- 관광지 상세
- 일정 에디터 (날짜 탭 + 장소 카드 + 메모)

### 5-3. 여행 기록 (log 트랙)
- 사진 다중 업로드
- 사진 라이브러리 (그리드 / 지도 / 타임라인) — P1
- 사진 상세·메타 편집

### 5-4. 카드 생성 (log 트랙)
- **흐름**: Trip 선택 → 사진 고르기(**최대 10장**) → AI 디자인 생성 → 미리보기 → (편집) → 다운로드
- 카드 에디터 (좌: 캔버스 / 우: 사이드바) — P1
  - 각 요소를 가능한 한 모두 편집: 요소 제외(숨기기), 글씨 내용 수정, 스티커 추가·이동 등
- 카드 다운로드 (PNG)

### 5-5. 공유 (P2)
- (A) 열람 공유 페이지 — slug 링크, 읽기 전용 (F18)
- (B) 동행자 협업 화면 — 초대, 일정 확인 + 사진 공동 업로드 (F22)
